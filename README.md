# Renkan (連環)

> **Live Web App:** [Renkan (連環)](https://georgescutelnicu.github.io/Renkan/)

Renkan is a simple tool for exploring Japanese Kanji and Radicals.

### Why "Renkan"?
**Renkan (連環)** means "chain" or "linked rings." It represents how individual radicals link together to form kanji, and how kanji connect to one another through shared components.

### Features
- Browse Kanji organized by grade level
- Search Kanji by meaning or Radicals by name
- Animated stroke order diagrams for kanji
- Click any radical to see all the Kanji built from it
